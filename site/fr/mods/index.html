Faites-le à votre façon.

Zak se transforme en langage naturel : demandez à Claude Code ou à Codex un thème, une page Nouvel onglet ou une extension, et voyez le résultat aussitôt. Voici des mods à télécharger, avec le prompt qui les a créés.

Installer un mod

  1. Téléchargez-le et décompressez-le.
  2. Dans Zak : Réglages → Personnaliser → Dossier des mods → Ouvrir, puis déposez-y le dossier.
  3. Choisissez-le dans Thème ou Page Nouvel onglet.

Créer le vôtre

Copiez un prompt, adaptez-le et donnez-le à Claude Code ou Codex. Vous pouvez aussi activer « Laisser Claude Code ou Codex piloter Zak » : votre agent installe et essaie le mod pour vous. Lire le guide.

Le partager

Proposez-le dans docs/customize/mods par une pull request, avec son prompt : il rejoindra cette galerie.
