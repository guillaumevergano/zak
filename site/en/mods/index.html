Make it yours.

Zak changes in plain words: ask Claude Code or Codex for a theme, a new tab page or an extension, and see it at once. Here are mods to download, with the prompt that made them.

Install a mod

  1. Download it and unzip it.
  2. In Zak: Settings → Customize → Mods folder → Open, then drop the folder there.
  3. Pick it under Theme or New tab page.

Make your own

Copy a prompt, adapt it and give it to Claude Code or Codex. You can also turn on “Let Claude Code or Codex drive Zak”: your agent installs and tries the mod for you. Read the guide.

Share it

Propose it in docs/customize/mods with a pull request, along with its prompt: it will join this gallery.
